# DevOps Lab 1 - Foundations and Continuous Integration

## Project Overview
This project demonstrates a basic web application and
the implementation of DevOps practices using Git,
GitHub, and Jenkins.

## Technologies Used
- Ubuntu Linux 24.04
- Visual Studio Code
- Git
- GitHub
- Jenkins
- HTML and CSS

## Application
A simple responsive HTML webpage created as part of
the DevOps Foundations and Continuous Integration lab.

## CI/CD Workflow
1. Source code is maintained using Git.
2. Code is pushed to GitHub.
3. Jenkins fetches the source code.
4. The pipeline performs build and test stages.
5. The application is deployed automatically.
